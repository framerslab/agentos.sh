# Support

- **Questions and discussion:** [Discord](https://wilds.ai/discord). GitHub issues are for bugs and feature requests.
- **Documentation:** [docs.agentos.sh](https://docs.agentos.sh)
- **Problems with the site and feature requests:** the [issue forms](https://github.com/framerslab/agentos.sh/issues/new/choose). Search the existing issues first. A bug in the runtime belongs in [agentos](https://github.com/framerslab/agentos/issues/new/choose), and a problem with a page on docs.agentos.sh belongs in [agentos-live-docs](https://github.com/framerslab/agentos-live-docs/issues).
- **Blog comments:** each post's comments are kept in this repository's [Discussions](https://github.com/framerslab/agentos.sh/discussions).
- **Security issues:** report privately as the [security policy](https://github.com/framerslab/agentos.sh/blob/master/.github/SECURITY.md) describes, never in a public issue.
- **Commercial, partnership or sponsorship inquiries:** team@frame.dev

To contribute, see [CONTRIBUTING.md](https://github.com/framerslab/agentos.sh/blob/master/CONTRIBUTING.md).
